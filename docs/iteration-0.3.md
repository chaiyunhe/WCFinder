# 0.3 迭代验收

本次代码用于下一版本开发，不自动覆盖正在审核的 0.2.0，也不自动部署生产云函数。

## 验收范围

- 默认找厕所；切换 AED、停车场后重新查询，标题、列表、地图、导航对应当前类别。
- 首次说明定位用途，同意后识别当前城市；拒绝或定位失败时可手动选择城市搜索。
- 北京、上海、广州、深圳、宁波、苏州、福州及其他省会城市可切换查询。
- 真实用户位置与地图查看中心分开保存；选中地点、切城不改写用户位置。
- 已定位时展示约直线距离并升序排列；未定位时不显示虚构距离。
- 城市搜索与附近搜索语义分开，切到外地后城市查询不会误查当前位置周边。
- 快速切换城市、类别时旧请求与旧定位回调不会覆盖最新选择。
- AED 结果仅表示地图收录地点，不承诺设备可用、开放或可立即取得。

## 发布前

1. 在独立测试云环境部署本次函数并配置高德 Key，不把 Key 放入客户端或 Git。
2. 用实际高德权限验证跨城市查询、AED 数据覆盖和逆地理编码；检查配额。
3. 微信真机验证位置授权、拒绝授权、城市切换、距离、地图与导航。
4. 同步修改微信后台隐私指引：定位用于识别当前城市、附近设施查询和距离计算，坐标传给高德处理。
5. 0.2.0 审核完成后安排新版本提交；生产部署与上传需确认候选版本验收结果。
