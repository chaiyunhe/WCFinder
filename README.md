# WCFinder

面向外出场景的找厕所应用。目前为静态交互原型，尚未上线。

## 本地运行

可直接用浏览器打开 `index.html`，或者在本目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8080 。按 Ctrl+C 停止服务。
无需安装前端依赖或配置地图密钥。

## 文件

- `index.html`：页面、筛选入口和反馈表单。
- `styles.css`：桌面和移动端布局。
- `app.js`：模拟点位、组合筛选、详情、评价和临时反馈。
- `assets/map-district.svg`：示意地图。

## 已有功能与限制

支持男厕、女厕、男女同区、第三卫生间及设施组合筛选，展示楼层、入口提示和示例评价。

地图、当前位置、距离、路线、评分和营业状态均为演示数据，不代表上海真实地点。
定位按钮仅播放动画；路线按钮尚未接入导航。反馈仅保存在当前页面内存中，刷新即丢失。
没有后端、数据库、账号系统或微信小程序工程。数据页中的交叉校验等能力为规划说明。
