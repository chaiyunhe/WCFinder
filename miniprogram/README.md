# WCFinder 微信小程序

AppID：`wx7f158580754f0989`。

当前本地代码已改为真实服务接入版本，尚未部署后端或进行实际 API 联调。微信已上传的 0.1.0 仍是原演示开发版，本次未覆盖。

## 已准备

- 上海地点/厕所关键词查询；主动点击并确认后定位查询附近。
- 原生地图点位、结果列表、打开地图导航。
- 查询错误、空结果、请求超时和过期响应处理。
- 不回退虚构数据，不展示虚构评分、营业状态或站台信息。
- 暂不提供无后端的反馈及未开通的收款入口。

## 配置

先按 `../server/README.md` 部署服务，再在 `services/api-config.js` 填 HTTPS 根地址。
高德 Key 放服务器环境变量，不放小程序。微信后台配置 request 合法域名、定位接口权限及隐私说明，完成真机测试后再上传提审。

在微信开发者工具导入此目录，或导入已配置 miniprogramRoot 的仓库根目录。无需 npm 构建。

测试：在仓库根目录执行 `node tests/miniprogram.cjs`。测试覆盖接口状态逻辑，不能代替微信编译、真机验证和真实供应商联调。

原 `services/restroom-service.js` 为历史演示服务，当前页面不再引用；`scripts/sync-miniprogram.cjs` 只更新历史演示副本，不配置线上接口。
