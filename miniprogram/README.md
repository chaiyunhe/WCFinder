# WCFinder 微信小程序

这是可导入微信开发者工具的原生小程序源码。全部地点、线路和示意图均为演示数据，尚未发布。

## 导入运行

1. 安装并登录微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选择“导入项目”，目录选择本文件所在的 `miniprogram` 文件夹（不是 WCFinder 根目录）。
3. 项目已配置 AppID `wx7f158580754f0989`，使用具有该小程序开发权限的微信账号登录工具。
4. 后端服务选择“不使用云服务”，点击编译。无需 npm 安装或构建。
5. 真机预览、上传和发布需使用你的小程序 AppID，并由对应开发者账号操作。

## 已实现

- 关键词搜索、地铁线路/站点联动、站厅/站台/站外筛选。
- 厕所类型及设施组合筛选、空结果提示和清除条件。
- 列表与示意点位联动、选中厕所详情。
- 手机切换列表与地图；宽屏左侧上方筛选、下方列表，右侧示意地图。
- 新增现场反馈、必填校验；反馈仅在本次页面运行期间保留。

没有真实 GPS、地图 SDK、路线规划、服务器或持久化数据。反馈的图上位置是占位，不表示实际坐标；不能据此导航。
页面用 WXML 文本绑定展示用户反馈，不将输入解析为 HTML。

## 复用网页版查询逻辑

`services/restroom-service.js` 由根目录 `restroom-service.js` 生成。
在仓库根目录执行 `node scripts/sync-miniprogram.cjs` 更新，不直接修改生成文件。
生成时将 `structuredClone` 换成适合当前纯 JSON 数据的复制方式，不依赖浏览器 DOM。
运行 `node tests/miniprogram.cjs` 检查页面状态、筛选与反馈流程。

## 接真实服务前

需要小程序 AppID、经核对的服务类目及隐私配置、HTTPS 后端及合法请求域名。
高德 Web 服务密钥放服务器环境变量，不放小程序包内。地图组件和定位能力需按微信平台要求单独配置、授权和真机测试。
百度补充查询及合并策略须先核对数据使用授权。不要将演示坐标百分比直接当成经纬度。

本次已进行 JavaScript 与页面逻辑检查；微信开发者工具编译、真机兼容性和发布审核仍需验证。
