## 本次迭代

- 全国城市选择器，覆盖一线、省会及宁波、苏州、福州等城市；供应商数据覆盖可能有差异。
- 首次明确同意位置用途后识别当前城市。拒绝定位仍可手动选城，提供重新定位入口。
- 厕所为默认分类，可切换 AED、停车场。
- 有真实定位时按直线距离排序并显示约米/公里；切换城市仍使用真实当前位置，不以地图中心代替。未定位不显示距离。
- AED 点位不保证完整或设备可用，紧急情况提示拨打 120。
- 原生地图、列表、导航；防止过期查询和定位回调覆盖最新城市。

## 配置与发布

`services/api-config.js` 指定云环境及 `restroomSearch` 云函数，支持 HTTPS 服务回退。高德 Key 仅放服务端环境变量，不能放入小程序包。
本次后端与前端需要配套部署。上线前更新微信后台隐私指引（位置用于城市识别、三类附近查询与距离估算，高德接收查询坐标），完成微信编译与真机验收后上传新版本。

导入仓库根目录（已配置 miniprogramRoot），无需 npm 构建。

测试：`node tests/live-miniprogram.cjs`、`node tests/cloud-miniprogram.cjs`。本地测试不代替真机及实际供应商联调。

历史 `services/restroom-service.js`、`scripts/sync-miniprogram.cjs` 不参与当前在线查询。
